
# Smart Workout Recommender — Power BI Dashboard

## Project Overview

Smart Workout Recommender is a Power BI data analytics project designed to explore fitness user profiles, workout preferences, exercise ratings, and fitness goals.

The dashboard presents key metrics and interactive visualizations that help users understand patterns in fitness goals, experience levels, age groups, user personas, and exercise data.

## Project Objectives

- Analyze fitness user profiles and workout preferences.
- Understand the distribution of fitness goals and experience levels.
- Explore user personas and age distribution.
- Analyze exercise ratings and body-part representation.
- Build an interactive dashboard to support data exploration and reporting.

## Tools and Technologies

- Microsoft Power BI
- Power Query
- CSV Dataset
- Data Visualization
- GitHub

## Dataset Description

The original dataset contains 11,165 rows and 17 columns.

Important columns include:

- `user_id` — User identifier
- `age` — User age
- `fitness_goal` — Fitness goal
- `experience_level` — Workout experience level
- `persona` — User persona category
- `injury_constraint` — Recorded injury constraint
- `exercise_name` — Exercise name
- `bodyPart` — Body part associated with an exercise
- `equipment` — Exercise equipment
- `target_muscle` — Target muscle group
- `rating` — Exercise rating

Note: Dataset access and redistribution are subject to the original dataset's license. Any publicly shared data should be appropriately anonymized.

## Dashboard Features

### 1. Key Performance Indicators (KPIs)

- Total Users
- Total Exercises
- Total Fitness Goals
- Total Body Parts
- Average Rating
- Average Age

### 2. Fitness Goal Analysis

Explores how users are distributed across different fitness goals.

### 3. Experience Level Analysis

Compares users across workout experience levels.

### 4. User Persona Analysis

Visualizes the distribution of users across different persona categories.

### 5. Age Distribution

Examines the distribution of user ages.

### 6. Rating Distribution

Analyzes exercise ratings to understand how ratings are distributed in the dataset.

### 7. Interactive Filters

The dashboard includes filters for:

- Fitness Goal
- Experience Level
- Persona
- Injury Constraint
- Age

## Business Questions

- Which fitness goals are most common?
- Which experience level has the highest number of users?
- How are users distributed across different personas?
- What does the age distribution reveal?
- How are exercise ratings distributed?
- Which body parts appear most frequently in the exercise data?

## Key Insights

The dashboard is designed to identify patterns in fitness goals, experience levels, user personas, age groups, and exercise ratings.

Specific findings should be reported using verified dashboard results rather than assumptions.

## Limitations

This project focuses on descriptive analytics and visualization. It does not establish that an exercise is medically suitable for a particular person or provide clinically validated workout recommendations.
